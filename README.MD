## Overview
This project investigates the relationship between educational attainment and handgun-related activity across U.S. states using FBI Gun Data and U.S. Census data from 2011–2015.

## Tools & Skills
- **Python:** Pandas, NumPy, Matplotlib
- **Data Preparation:** Cleaning, transformation, and merging datasets
- **Analysis:** Exploratory data analysis, visualization, and correlation analysis

## Key Findings
The analysis found virtually no linear correlation (**r = 0.0038**) between the percentage of adults with a bachelor's degree or higher and handgun background-check counts.

## Lessons Learned
Revisiting this project taught me the importance of understanding what data actually measures.

I originally interpreted the FBI data as gun sales or ownership, but it represents firearm background checks, which do not necessarily indicate completed purchases.

This reinforced three important lessons:
- Verify data definitions and original sources.
- Consider population differences when comparing states.
- Distinguish statistical relationships from causal conclusions.

**Key takeaway:** Accurate analysis starts with understanding the data, not just knowing how to analyze it.
